SEC.01

基础化学

FUNDAMENTAL CHEMISTRY
KC-01

物质的量 Amount of Substance

一切化工计算的起点：n = m/M = V/Vm（标况下气体 Vm = 22.4 L/mol）。注意摩尔质量 M 以 g/mol 计，气体只有在标况（273.15 K，101.325 kPa）下才能直接用 22.4。

KC-02

化学平衡 Chemical Equilibrium

平衡常数 K 只随温度变化；勒夏特列原理判断移动方向。合成氨 N₂ + 3H₂ ⇌ 2NH₃ 为放热反应，低温有利平衡但速率慢，工业上采用中温高压加催化剂的折中方案。

KC-03

电化学基础 Electrochemistry

原电池：氧化在负极、还原在正极；电解池相反。能斯特方程描述浓度对电极电势的影响，是氯碱工业、电解精炼、腐蚀防护的理论基础。

SEC.02

化工原理 · 五大单元操作

UNIT OPERATIONS

单元操作（Unit Operations）是化工学科的"积木"——点击各章展开学习。

CH.01 流体流动 FLUID FLOW
连续性方程 Continuity Equation

不可压缩流体稳态流动时质量守恒：u₁A₁ = u₂A₂。管径缩小流速增大，是管路设计的第一约束。

伯努利方程 Bernoulli Equation
z1 + p1/ρg + u1²/2g = z2 + p2/ρg + u2²/2g + Σhf

位能、静压能、动能三项守恒，Σhf 为沿程阻力损失。用泵输送时再加输入功：+ H（扬程）。注意各项单位均为"米液柱"。

雷诺数与流型 Reynolds Number
Re = duρ/μ　（Re < 2000 层流 laminar；Re > 4000 湍流 turbulent）

Re 是惯性力与黏性力之比，量纲为 1。层流时流速呈抛物线分布（平均流速为最大流速的一半），湍流时速度分布平坦、传热传质更强。

流动阻力 Friction Loss
hf = λ·(L/d)·(u²/2g)　λ = f(Re, ε/d)

直管阻力用达西公式；局部阻力（弯头、阀门）常用当量长度法或阻力系数法。层流 λ = 64/Re，湍流用莫狄图（Moody Chart）查取。

离心泵与气蚀 Centrifugal Pump / Cavitation

扬程（head）指泵给单位重量流体增加的能量；安装高度过高会使泵入口压力低于液体饱和蒸气压，产生气蚀（cavitation）——表现为噪音、振动与性能骤降，必须保证 NPSH安 ≥ NPSH需 + 0.5 m 安全裕量。

CH.02 传热 HEAT TRANSFER
三种传热方式 Conduction / Convection / Radiation

热传导（conduction）依靠分子振动，发生于固体或静止流体层；对流传热（convection）依靠流体宏观流动；热辐射（radiation）不需要介质，遵循四次方定律。

傅里叶定律 Fourier's Law
Q = -λ·A·(dT/dx)　→　平壁稳态：Q = λAΔt/b

λ 为导热系数（thermal conductivity），金属可达数十到数百 W/(m·K)，保温材料 < 0.1。多层壁用热阻串联：Σ(b/λA)，与电路欧姆定律完全类比。

总传热速率 Overall Heat Transfer
Q = K·A·Δtm　1/K = 1/αi + b/λ + 1/αo + R垢

K 为总传热系数，由两侧对流传热系数、壁面导热与污垢热阻共同决定——污垢热阻（fouling）常成为主导，工程上换热器要留 15%–25% 的面积裕度。

对数平均温差 LMTD
Δtm = (Δt大 - Δt小) / ln(Δt大/Δt小)

换热器两端温差不等时取对数平均。逆流（counter-current）比并流（co-current）的平均温差大、传热更充分，且冷流体出口温度可高于热流体出口温度。

换热设备 Heat Exchangers

列管式（shell-and-tube）最经典，可承受高压大流量；板式（plate）传热系数高、易拆洗；螺旋板式适合含颗粒物料。强化传热三途径：提高 K、增大 A、加大 Δtm。

CH.03 蒸馏与精馏 DISTILLATION
气液平衡基础 Vapor-Liquid Equilibrium

理想溶液服从拉乌尔定律（Raoult's law）：pA = pAo·xA。挥发度差异是蒸馏分离的根源：易挥发组分（more volatile component）在气相中富集。

相对挥发度 Relative Volatility
α = (y/(1-y)) / (x/(1-x))　→　y = αx / (1 + (α-1)x)

α = 1 时气液两相组成相同、无法分离；α 离 1 越远越易分离。α < 1.05 的体系（如丁烯异构体）蒸馏在经济上几乎不可行。

全塔物料衡算 Overall Material Balance
F = D + W　；　F·xF = D·xD + W·xW

F/D/W 为进料、馏出液、釜液流量。注意"清晰分割"（xD 近 1、xW 近 0）只是理想假设。

理论板与回流比 Theoretical Plate / Reflux Ratio

理论板指离开该板的气液两相达到平衡的理想塔板。回流比 R = L/D 是精馏的"灵魂参数"：全回流时理论板数最少（芬斯克方程），R 增大操作线远离平衡线、板数减少但能耗上升，实际在最小回流比 Rmin 的 1.2–2 倍间取经济最优。

Nmin = ln[ xD(1-xW) / xW(1-xD) ] / ln α
进料热状态与塔设备 Feed Condition / Columns

进料热状态 q（过冷液体到过热蒸气）决定 q 线位置。塔设备分板式塔（tray column：泡罩、筛板、浮阀）与填料塔（packed column），前者适合大直径、抗堵塞，后者压降低、效率高。

CH.04 吸收 ABSORPTION
亨利定律 Henry's Law
p* = E·x　（E 为亨利系数；溶解度越大 E 越小）

气液平衡是吸收的极限：液相浓度低于平衡浓度才能继续吸收。工业吸收剂的要求：溶解度大、选择性高、蒸气压低、易再生、腐蚀性小。

气膜与液膜控制 Film Control

双膜理论（two-film theory）把传质阻力集中在气液两侧的膜内。易溶气体（如 NH₃-水）为气膜控制——增大气速有效；难溶气体（如 CO₂-水）为液膜控制——增大喷淋量有效。

填料塔 Packed Column

填料（拉西环、鲍尔环、规整填料）提供气液接触表面；液体靠分布器均匀喷淋，气体逆流而上。关键水力学指标是液泛气速（flooding velocity），实际操作气速取液泛气速的 0.6–0.8 倍。

传质单元 NTU / HTU
Z = HOG · NOG

填料层高度 = 传质单元高度 HTU（设备性能）× 传质单元数 NTU（分离任务难度）。解吸（stripping）是吸收的逆过程，常用于溶剂再生。

CH.05 干燥 DRYING
湿空气性质 Humid Air Properties
H = 0.622 · pv / (P - pv)

湿度 H（humidity ratio）、相对湿度 φ、干球/湿球温度（dry/wet bulb temperature）、焓 I 与露点（dew point）。湿球温度是绝热饱和过程的渐近温度，干燥速率计算的核心参数。

干燥速率曲线 Drying Rate Curve

恒速阶段（constant-rate period）由表面汽化控制，速率取决于外部空气条件；降速阶段（falling-rate period）由内部水分迁移控制，提高气温效果有限。转折点为临界含水量（critical moisture content），物料只能干燥到平衡含水量（equilibrium moisture content）为止。

典型干燥器 Dryers

气流干燥器（pneumatic）适合粉状、耐高温物料；流化床（fluidized bed）传热强、停留时间可调；喷雾干燥（spray drying）直接从溶液/悬浮液一步到粉体，广泛用于奶粉、染料、催化剂制备。

CH.06 其他单元操作速览 OTHER OPERATIONS
蒸发 Evaporation

浓缩溶液的操作。多效蒸发（multi-effect evaporation）用前一效的二次蒸汽加热后一效，显著降低蒸汽消耗；温差损失（沸点升高）限制效数，一般 2–4 效。

萃取 Liquid-Liquid Extraction

利用溶质在互不相溶液体间分配的不同实现分离，适用于热敏、沸点接近体系。三角形相图（ternary diagram）中的联结线（tie line）是计算的理论基础。

结晶 Crystallization

过饱和度（supersaturation）是结晶的驱动力：过饱和曲线与溶解度曲线之间的"介稳区"是工业操作的黄金区域。晶核生成与晶体生长的竞争决定粒度分布。

膜分离 Membrane Separation

反渗透（RO）、超滤（UF）、纳滤（NF）、电渗析（ED）按截留分子量分级驱动，无相变、低能耗，是水处理与原料药纯化的主流技术。

SEC.03

反应工程

CHEMICAL REACTION ENGINEERING
RATE

反应速率与温度

k = k0·exp(-Ea/RT)

阿伦尼乌斯方程：温度每升高 10°C，速率约提高 2–4 倍（经验规则）。活化能 Ea 越大，反应对温度越敏感 —— 这也是"热点"（hot spot）失控的根源。

RTD

停留时间分布 RESIDENCE TIME DISTRIBUTION

实际反应器中粒子停留时间不均一。理想模型是两个极端：平推流（所有粒子同时进出）与全混流（完全返混）。用脉冲示踪或阶跃示踪实验测定 E(t) 曲线即可诊断返混程度。

COMPARE

三种理想反应器对比

类型英文混合特性适用场景典型设备
间歇反应器Batch Reactor (BRT)批次内均匀，无物料进出小批量、多品种、反应慢反应釜 / 搪瓷釜
全混流反应器CSTR完全返混，出口 = 釜内液相、需控温、自催化带搅拌的连续釜
平推流反应器PFR无返混，像"列车行进"大产量、气相、高压列管式固定床

同样体积下，对正级数反应 PFR 的转化率恒高于 CSTR；需要维持低浓度（如抑制副反应或放热失控）时反而选 CSTR，还可多釜串联取两者折中。

SEC.04

典型工艺案例

INDUSTRIAL PROCESSES
HABER

合成氨

N2 + 3H2 ⇌ 2NH3　ΔH < 0

400–500°C、15–30 MPa、铁基催化剂。流程：造气 → 脱硫变换 → 深冷净化 → 合成塔 → 冷凝分离 → 循环。是"平衡与速率博弈"的教科书案例，也是养活全球一半人口的化肥工业基石。

REFINERY

石油炼制

常减压蒸馏按沸点切割馏分；催化裂化（FCC，分子筛催化剂）把重油变汽油；加氢精制脱硫脱氮；催化重整产芳烃与氢气。整个炼厂本质上就是一台巨大的"蒸馏塔 + 反应器"网络。

H₂SO₄

接触法硫酸

SO₂ 经 V₂O₅ 催化氧化为 SO₃（多层催化床段间换热，绝热操作线经典），再经 98% 酸吸收成发烟硫酸。段间冷却与"冷激"设计是"放热反应器多段绝热"的标杆案例。

SEC.05

安全与环保

SAFETY & ENVIRONMENT
SAFETY

工艺安全管理

爆炸极限 LEL / UEL

可燃气在空气中的体积分数低于 LEL（爆炸下限）或高于 UEL（爆炸上限）均不燃不爆。在线检测仪报警值常设 25% LEL。

HAZOP 分析

以"引导词 + 工艺参数"（如 No + Flow = 无流量）系统化遍历偏差，识别风险并落地对策，是化工设计安全审查的国际通用方法。

SDS 安全数据表 Safety Data Sheet

16 项标准内容：理化性质、危险性概述、急救 / 消防 / 泄漏处置、接触控制等。接触任何新化学品前先读 SDS 是铁律。

GREEN

绿色化工

原子经济性 Atom Economy

目标产物分子量占投料总分子量之比。原子经济性高的工艺（如环氧丙烷的 HPPO 法）从源头减少废物，优于末端治理。

三废治理

废水（生化 + 深度氧化）、废气（吸收 / 吸附 / RTO 燃烧）、固废（资源化 + 危废焚烧填埋）。"清洁生产审核"要求从工艺源头减量。

本质安全化 Inherent Safety

四条原则：最小化（intensification）、替代（substitution）、缓和（attenuation）、简化（simplification）—— 最好的安全是让危险不存在，而非依靠防护。
